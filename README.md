# Bingowon Orchardgrid

## How do I install these formulae?

`brew install bingowon/orchardgrid/<formula>`

Or `brew tap bingowon/orchardgrid` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "bingowon/orchardgrid"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
